# Gather & Graze

A simple, responsive recipe website with three approachable recipes, ingredient lists, and step-by-step instructions. The page is built with plain HTML and CSS, so it needs no dependencies or build tools.

## View the website

Open `index.html` in any modern web browser. You can also serve the repository directory locally:

```sh
python3 -m http.server
```

Then visit [http://localhost:8000](http://localhost:8000).
